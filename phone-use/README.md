# axuse phone-use

Phone control for AI agents under the axuse brand: accessibility-first, with no vision model.

| Platform | Status | Docs |
|---|---|---|
| Android (**axdroid**) | Available. 116 of 116 tasks on AndroidWorld in a single pass. | [android/README.md](android/README.md) · [AndroidWorld results](android/androidworld/README.md) |
| iPhone (**axphone**) | Coming soon | |

axdroid reads an Android screen through the phone's own accessibility tree (no screenshots) and acts through the same accessibility actions. The easiest way to set it up is to paste this sentence into your AI agent:

> Install axdroid by following https://ax-use.com/install-phone.md

More at https://ax-use.com/phone-use/.
