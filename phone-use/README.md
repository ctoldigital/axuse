# axuse phone-use

Phone use for AI agents under the axuse brand: accessibility-first, with no vision model.

| Platform | Status | Docs |
|---|---|---|
| Android (**axdroid**) | Available. An agent using it completed 116 of 116 AndroidWorld tasks in a single pass. | [android/README.md](android/README.md) · [AndroidWorld results](android/androidworld/README.md) |
| iPhone (**axphone**) | Coming soon | |

axdroid is a phone-use library, not an agent: it gives AI agents such as Codex, Claude Code, ChatGPT Work, Dots, Meta Muse, OpenCode, Devin, Cursor and Antigravity a real Android phone to use, reading the screen through the phone's own accessibility tree (no screenshots) and acting through the same accessibility actions. The easiest way to set it up is to paste this sentence into your AI agent:

> Install axdroid by following https://ax-use.com/install-phone.md

More at https://ax-use.com/phone-use/.
